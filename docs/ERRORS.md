# Ошибки и как их не повторять

- Не путать «Щиток» с одноимёнными репозиториями: исходник находился в `dd77yy77-wq/UltraPDF/shchitok`; новый проект живёт только в `dd77yy77-wq/shchitok-2`.
- Не редактировать статичный список устройств независимо от подписей автоматов: обе части используют `shchitok2.state.v1`.
- Скрытые поля формы: авторский CSS может перекрыть атрибут `hidden`; обязателен `[hidden]{display:none!important}` и проверка снимком.
- В обработчиках циклов не использовать общие `var` без функциональной области: рендер каждой категории вынесен в отдельную функцию.
- Подпись v2: неверный префикс длины → всегда проверять `apkbuild.v2_verify` и `jarsigner -verify`.
- Playwright: `Locator.screenshot(clip=...)` не поддерживается → использовать `page.screenshot(clip=...)`.
- Схемы и формы проверять на экране 412×860; предупреждающий треугольник не должен перекрывать кнопки.
- Не публиковать `keys/shchitok2.p12`; не создавать новый ключ при каждой сборке, иначе обновления перестанут устанавливаться поверх.
